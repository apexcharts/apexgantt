ApexGantt: Toolbar Extensibility Demo

Click a task row to select it, then press Space to toggle selection. Use the Phase dropdown to show only the tasks of one phase. Select tasks, then use Publish to act on them, or pick a tag in the Tag dropdown and click Apply tag: the tag is stored on each task and shown in the Tag column.

What's demonstrated

  • Phase filter: calls gantt.filter(predicate) and gantt.clearFilter(), which hide and show rows without changing the data
  • Publish: requiresSelection, showCount, shows a toast on click
  • Copy IDs: disabled: fn evaluated live, writes to clipboard
  • Tag select + Apply tag: the select keeps the tag you picked, and the button stores it on each selected task with gantt.updateTask(), so the same tag can go on one task after another; a custom Tag column renders it, and its accessor makes the column sortable
  • Space: toggles selection after clicking a row (keyboard focus follows click)
  • Ctrl/Cmd+A: selects all tasks
  • Escape: clears selection
  • ↑ ↓: navigate rows
